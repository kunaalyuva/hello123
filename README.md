📝 AiReadmeGen: Automated README Generation with Local LLMs

AiReadmeGen is a Python-based tool designed to streamline the documentation process by leveraging local large language models (LLMs) via Ollama. It automatically generates comprehensive and professional `README.md` files for your projects, providing detailed descriptions, feature lists, and setup instructions. This project aims to empower developers with quick, context-aware documentation, with an additional utility to export the generated README as a PDF.

---

### ✨ Features

*   **🧠 AI-Powered Content Generation**: Dynamically creates rich README content using a locally hosted Ollama language model.
*   **📝 Markdown Output**: Generates standard `README.md` files, ensuring compatibility and easy integration into any project.
*   **📄 PDF Export Functionality**: Converts the generated Markdown into a professional PDF document for shareable, static documentation.
*   **🖥️ Local LLM Execution**: Operates entirely with local models through Ollama, ensuring data privacy and reducing reliance on cloud services.
*   **⚙️ Modular Design**: Separates concerns into distinct modules for AI interaction, markdown-to-PDF conversion, and main application logic.

### 🛠️ Tech Stack

This project is built using the following core technologies:

*   **Backend**:
    *   Python 3.x
*   **Tools**:
    *   Ollama (for local LLM hosting and interaction)

### 🏗️ Architecture

AiReadmeGen follows a modular, sequential processing architecture. The `main.py` script acts as the central orchestrator, coordinating the workflow:

1.  **Input Processing**: Gathers project information (either user-provided or inferred).
2.  **AI Generation Layer**: The `ollama_model.py` module interacts with the locally running Ollama server to prompt a configured large language model. This layer is responsible for generating the core README content in Markdown format.
3.  **Markdown-to-PDF Conversion Layer**: The `markdown_to_pdf.py` module takes the generated Markdown content and converts it into a formatted PDF document.
4.  **Output Handling**: `main.py` then manages saving both the `.md` and `.pdf` outputs to the specified locations.

This design emphasizes clear separation of concerns, making the system easy to understand and maintain.

### 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine.

#### Prerequisites

Before you begin, ensure you have the following installed:

*   **Python 3.x**: Download from [python.org](https://www.python.org/downloads/).
*   **Ollama**: Install Ollama from [ollama.com](https://ollama.com/download) and ensure it's running.
    *   Pull a language model (e.g., `llama2`) using `ollama pull llama2`.

#### Installation

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/your-username/AiReadmeGen.git
    cd AiReadmeGen
    ```

2.  **Install Python dependencies**:
    While a `requirements.txt` is not provided in this structure, you will likely need libraries for Markdown processing and PDF generation. Install common ones:
    ```bash
    pip install markdown-it-py PyPDF2
    ```
    *(Note: Specific libraries for markdown-to-pdf conversion may vary based on implementation in `markdown_to_pdf.py`.)*

#### Running the Application

1.  **Ensure Ollama is running**:
    Verify that the Ollama server is active and the required model (e.g., `llama2`) is available.

2.  **Execute the main script**:
    ```bash
    python main.py
    ```
    The script will interact with your local Ollama instance, generate a README, and optionally convert it to PDF. The output will be saved as `README.md` and `Output.pdf` (or similar, depending on the script's configuration).
